# Advanced DoS Simulator - Educational Tool

## 🚨 IMPORTANT NOTICE
**FOR EDUCATIONAL PURPOSES ONLY** - This tool simulates DoS attacks without transmitting actual network packets. It is designed for cybersecurity education and awareness in controlled environments.

## Features
- 8 Different DoS Attack Simulations (SYN Flood, UDP Flood, HTTP Flood, Slowloris, ICMP Flood, DNS/NTP/SNMP Amplification)
- Real-time Resource Monitoring & Visualization
- Safety-First Design (No Actual Network Harm)
- Cross-Platform Compatibility (Windows, Linux, macOS)
- Comprehensive Logging and Data Export
- Clean White Theme Interface

## Installation
```bash
git clone https://github.com/mphosiphosenkosi-collab/advanced-dos-simulator.git
cd advanced-dos-simulator
pip install -r requirements.txt
python src/dos_simulator.py
Usage
Select attack type from dropdown

Configure target parameters (IP, port)

Set thread count and timing parameters

Click "Start Attack" to begin simulation

Monitor real-time statistics and graphs

Use "Stop Attack" to end simulation

Safety Features
No actual network packet transmission

Resource usage monitoring and limits

Educational context warnings
