## Code Architecture

### Main Components:
1. **DoSSimulatorApp** - Main application class
2. **Attack Simulation Engine** - Multi-threaded attack simulation
3. **GUI Framework** - Tkinter-based user interface
4. **Data Visualization** - Matplotlib integration
5. **Resource Monitor** - System resource tracking
6. **Safety Manager** - Educational safeguards

### Key Features Implemented:
- 8 attack type simulations
- Real-time graphing and statistics
- Cross-platform compatibility
- Comprehensive logging system
- Safety protocols (no actual network transmission)
